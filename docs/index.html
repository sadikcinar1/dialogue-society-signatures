Adding it to your email

Once per program. Press Copy signature first — copy the preview, not the HTML, because that is what carries the logo.

Gmail

  1. Press Copy signature above.
  2. In Gmail, open the gear icon → See all settings.
  3. On the General tab, scroll to Signature and press Create new.
  4. Click into the editing box and paste with ⌘V.
  5. Under Signature defaults, select it for new emails and for replies / forwards.
  6. Press Save Changes at the bottom of the page.

Apple Mail

  1. Press Copy signature above.
  2. In Mail, open Mail → Settings → Signatures.
  3. Select your account, press +, and name it Dialogue Society.
  4. Untick Always match my default message font. Skip this and Mail strips the styling out.
  5. Drag the Settings window wider if it is narrow — the signature pane grows with it, and a pane narrower than the signature is what pushes the logo onto its own line.
  6. Click into the right-hand pane and paste with ⌘V.
  7. Set Choose Signature to it so it is added automatically.

Outlook on Windows

  1. Press Download for Outlook above.
  2. Press Windows + R, type %appdata%\Microsoft\Signatures and press Enter.
  3. Move the downloaded file into that folder.
  4. In Outlook, open File → Options → Mail → Signatures and it will be listed.
  5. Set it as the default for New messages and Replies/forwards.

iPhone and iPad

  1. Open Settings → Apps → Mail → Signature.
  2. Phone signatures are plain text — no logo or blue rule is possible.
  3. Use four lines: your name, your job title, Dialogue Society, and www.dialoguesociety.org.

Which one do I use?

The difference is who the mail is from, not how formal it is.

Use Personal for your own mail

Anything you write as yourself. A named sender is easier to reply to and easier to trust.

Use Branch for shared inboxes

Addresses answered by whoever is on duty — info@, a branch address, bookings, enquiries. Naming one person makes every reply look like it came from them.

Use Branch for announcements

Newsletters and mail sent by the organisation rather than by a colleague.

Regions go on the Branch form

The region is appended to the name — Dialogue Society Birmingham — so a branch reads as part of the whole.

House rules

RuleWhy
Use this page, not a colleague’s signature Editing someone else’s copy is how the old house blue drifted to #0797C8 when the brand blue is #008AC4.
Write the address as your office registers it So post, the website and search results all agree.
Type the region, not the whole name The region is appended to “Dialogue Society”. Typing the full name gives you “Dialogue Society Dialogue Society Sheffield”.
Keep the charity line A registered charity must state its number on correspondence.
Branch signatures name no one A shared inbox is answered by whoever is on duty. Putting one person on it makes replies look like they came from them.
Nothing extra underneath Quotes, slogans and campaign banners sit outside the checked colour set and land in every reply chain you join.
