Setting it up

Once per mail client.

Gmail

  1. Press Copy signature above.
  2. In Gmail, open the gear icon → See all settings.
  3. On the General tab, scroll to Signature and press Create new.
  4. Click into the editing box and paste with ⌘V.
  5. Under Signature defaults, select it for new emails and for replies / forwards.
  6. Press Save Changes at the bottom of the page.

Apple Mail

  1. Press Copy signature above.
  2. In Mail, open Mail → Settings → Signatures.
  3. Select your account, press +, and name it Dialogue Society.
  4. Untick Always match my default message font. Skip this and Mail strips the styling out.
  5. Drag the Settings window wider if it is narrow — the signature pane grows with it, and a pane narrower than the signature is what pushes the logo onto its own line.
  6. Click into the right-hand pane and paste with ⌘V.
  7. Set Choose Signature to it so it is added automatically.

Outlook on Windows

  1. Press Copy signature above.
  2. In Outlook, open File → Options → Mail → Signatures.
  3. Press New and name it Dialogue Society.
  4. Click into the edit box and paste with Ctrl + V.
  5. Set it as the default for new messages and for replies.

iPhone and iPad

  1. Open Settings → Apps → Mail → Signature.
  2. Phone signatures are plain text, so no logo or blue rule is possible.
  3. Use three lines: your name or Dialogue Society, your role or motto, and www.dialoguesociety.org.
